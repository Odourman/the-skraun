## TV-standard – korrigering

The Skraun är **NTSC-mål**, samma projektinriktning som The Cabin/Let Me Out! Inget uttryckligt PAL-beslut eller ROM-byte till 312-linjers PAL existerar. Officiella Stella-dokumentationen https://stella-emu.github.io/docs/ (avsnitt Display Format) anger att `NTSC*` / `PAL*` med asterisk betyder **autodetekterad formatetikett**, inte bevis på korrekt 262-radig NTSC-frame. Klassisk Atari TIA NTSC-programmering använder 262 rasterrader, cirka 60 Hz, 76 6507-cykler/rad. PAL typiskt 312 rader, cirka 50 Hz. En första, överbelastad PLAY1-X-kandidat identifierades som `PAL*`, inte för att spelet utvecklats som PAL utan för att rad-/frametimingen blivit fel. Slutvarianten identifieras `NTSC*` men visar ändå 273/285/297 rader och **är INTE NTSC-kompatibel som korrekt renderer**.
