### Defects actually found and fixed
1. Initial direction logic did X then Y, allowing a diagonal to cut a solid corner. Source oracle found it; candidate validity now checks both original-axis projections plus destination.
2. First real Stella run (#44072526200) assembled and made screenshots, but exact sprite readout revealed clipped final row and incorrect captured Level2 after quick F1 press.
3. Second strict visual run (#44072903382) fixed row visibility partly but produced **37 instead of 36** L3 rows, and partial pixel corruption from late GRP0 midline writes. Replaced visual kernel with early `STA GRP0` after `WSYNC` and previous-line sprite preloading; subsequent REAL Stella pixel exact PASS.
4. A CI rerun initially failed *without starting Stella* due an apostrophe inside a single-quoted Bash script comment (not actual code fault). Removed comment apostrophe and replaced four-second window assumption with Stella-FAQ-supported up-to-30-second window polling, preserving diagnostics. This reproduced the successful actual script/test.
